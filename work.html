01 · Systems & Simulation · 2025 · Hackathon Winner · SimVerse ’25
SimVerse ’25 — 1st Place Winner

Gravity Sandbox

Real-time collaborative N-body astrophysics simulation

A collaborative astrophysics sandbox allowing multiple users to interact with multi-body gravitational mechanics in the browser. Built with a Host-Relay WebSocket architecture so one client computes physics state updates and broadcasts them to connected peers without running centralized physics servers.

React · Three.js · Socket.io · Node.js · Physics Engine
Technical Details
  • Host-Relay synchronization topology over WebSockets (Socket.io + Node.js)
  • Client-side N-body gravitational simulation engine without server-side compute
  • Interactive 3D browser visualization rendered using Three.js
GitHub ↗
1. Problem Context

Synchronizing multi-user gravitational simulations via centralized physics servers adds hosting overhead and network round-trip latency for every step.

2. Implementation

Implemented a Host-Relay architecture where one designated host client computes the N-body physics state and broadcasts updates to connected viewers sharing the Three.js scene.

3. Outcome

Awarded 1st Place at SimVerse ’25 for delivering real-time collaborative physics interaction in the browser.

03 · Computer Vision & GIS · 2025 · Hackathon Prototype · ISRO Track
ISRO Hackathon Prototype

Geospatial Change Detection

Multi-temporal satellite imagery & cloud-masking pipeline

An automated remote sensing prototype engineered for the ISRO Hackathon to surface land-use and environmental changes across multi-temporal satellite captures. Preprocesses raster tiles with cloud masking and persists spatial change records into PostGIS.

Python · FastAPI · PostGIS · Rasterio · Celery · Vue.js
Technical Details
  • Raster preprocessing and cloud masking built on Python and Rasterio
  • Asynchronous task queue using Celery and FastAPI for multi-date comparisons
  • Spatial results persisted in PostGIS and displayed via a Vue.js interface
GitHub ↗
1. Problem Context

Manual inspection of multi-temporal satellite captures is slow and frequently disrupted by transient cloud cover causing false change alerts.

2. Implementation

Constructed a FastAPI and Celery pipeline using Rasterio to apply cloud-masking filters before comparing multi-date captures and saving spatial footprints to PostGIS.

3. Outcome

Delivered a complete GIS monitoring prototype handling automated tile ingestion, filtering, and spatial alert generation.

05 · Robotics & Hardware · 2025 · Undergraduate Research Prototype
Undergraduate Research · VIT-AP ECS

Autonomous Human-Following Robot

Microcontroller mobile robotics prototype with sensor fusion

An embedded robotics research prototype built in the School of Electronics & Computer Science (VIT-AP University) under faculty supervision of Dr. Y. Narasimha Rao. Combines Arduino UNO R3 firmware, ultrasonic and infrared sensors, and differential-drive DC motors to track a moving human target.

Arduino UNO · Embedded C++ · IR & Ultrasonic Sensors · Differential Drive
Technical Details
  • Sensor fusion logic pairing ultrasonic rangefinding with infrared proximity sensors
  • Embedded C++ firmware running on Arduino UNO R3 with obstacle avoidance
  • Differential-drive motor actuation driven by geared DC motors
1. Problem Context

Tracking a moving human target with low-cost sensors involves filtering noisy readings and reacting quickly to obstacles inside indoor spaces.

2. Implementation

Implemented embedded C++ sensor fusion on Arduino UNO R3 combining ultrasonic and IR arrays to steer differential-drive DC geared motors smoothly.

3. Outcome

Demonstrated an autonomous hardware tracking prototype as part of undergraduate ECS departmental research.
